# Portafolio de seguridad y desarrollo

Notas, ejercicios y casos de práctica de mi camino para formarme en desarrollo
backend y ciberseguridad, con foco en pentesting web.

## Sobre mí

Estudiante autodidacta de programación y seguridad informática, en Paraguay.
Combino el aprendizaje con la práctica real: audito mis propios proyectos para
entender vulnerabilidades de principio a fin, no solo en teoría.

## Ruta de estudio

1. **Fundamentos**: Linux, terminal, Git, lógica de programación.
2. **JavaScript**: desde variables hasta asincronía y pruebas automáticas.
3. **Redes**: TCP/IP, HTTP, DNS, análisis de tráfico con Wireshark.
4. **Backend y APIs**: Node.js, Express, PostgreSQL, autenticación.
5. **Seguridad**: OWASP Top 10, laboratorios de PortSwigger, auditorías propias.
